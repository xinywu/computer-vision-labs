# 实验四详细设计

## 1 模块说明

本实验将边缘检测和图像分割功能集中在 `edge_segmentation.py` 中。程序读取一张清晰纹理图和一张光照不均图，依次完成 Sobel 梯度、Canny 边缘检测、全局阈值分割和自适应阈值分割，并将结果保存到 `results` 文件夹。

## 3 函数设计

### 3.1 read_gray

功能：以灰度模式读取指定图片。

输入：

- `filename`：图片文件名，字符串类型。

输出：

- OpenCV 灰度图像，类型为 `numpy.ndarray`。

处理过程：

1. 将实验数据目录和文件名组合成完整路径。
2. 使用 `cv2.imread` 的灰度模式读取图片。
3. 检查读取结果是否为空。
4. 返回灰度图像。

异常处理：

- 如果图片不存在、路径错误或图片损坏，抛出 `FileNotFoundError`，并显示无法读取的文件路径。

### 3.2 save_image

功能：把处理结果保存到 `results` 文件夹。

输入：

- `filename`：输出文件名。
- `image`：需要保存的图像数组。

输出：

- 无返回值，结果直接写入磁盘。

处理过程：

1. 组合结果目录和输出文件名。
2. 调用 `cv2.imwrite` 保存图像。
3. 保存成功后在终端显示文件名。

异常处理：

- 如果 OpenCV 返回保存失败，抛出 `OSError`。

### 3.3 run_sobel

功能：计算图像的 Sobel 梯度幅值，并比较不同卷积核尺寸。

输入：

- `image`：灰度图像。

输出：

- `sobel_k3.jpg`
- `sobel_k5.jpg`
- `sobel_comparison.jpg`

处理过程：

1. 分别选择大小为 3 和 5 的 Sobel 卷积核。
2. 计算 x 方向梯度和 y 方向梯度。
3. 根据公式 `G = sqrt(Gx² + Gy²)` 计算梯度幅值。
4. 将梯度幅值归一化到 0～255。
5. 转换为 `uint8` 类型并保存。
6. 水平拼接两种核尺寸的结果。

异常处理：

- 图像保存异常由 `save_image` 统一处理。
- 使用 `CV_64F` 保存正负梯度，避免直接转换为 `uint8` 时丢失负值。

### 3.4 run_canny

功能：使用三组双阈值进行 Canny 边缘检测。

输入：

- `image`：灰度图像。

输出：

- `canny_50_150.jpg`
- `canny_100_200.jpg`
- `canny_150_250.jpg`
- `canny_comparison.jpg`

处理过程：

1. 依次使用 `(50,150)`、`(100,200)` 和 `(150,250)` 三组阈值。
2. 调用 `cv2.Canny` 检测边缘。
3. 统计非零边缘像素占整张图的比例。
4. 保存各组结果和水平对比图。

异常处理：

- 输入图像由 `read_gray` 保证为有效灰度图。
- 图像保存异常由 `save_image` 统一处理。

### 3.5 run_global_threshold

功能：比较固定阈值分割和 Otsu 自动阈值分割。

输入：

- `image`：灰度图像。

输出：

- `threshold_fixed_128.jpg`
- `threshold_otsu.jpg`
- `threshold_comparison.jpg`

处理过程：

1. 使用固定阈值 128 完成二值分割。
2. 使用 Otsu 方法自动计算阈值。
3. 保存两种分割结果和对比图。
4. 在终端输出 Otsu 自动选择的阈值。

异常处理：

- 输入图像由 `read_gray` 统一检查。
- 图像保存异常由 `save_image` 统一处理。

### 3.6 run_adaptive_threshold

功能：比较光照不均图像上的全局 Otsu 和自适应阈值。

输入：

- `image`：光照不均的灰度图像。

输出：

- `uneven_otsu.jpg`
- `uneven_adaptive.jpg`
- `adaptive_comparison.jpg`

处理过程：

1. 使用 Otsu 方法进行全局阈值分割。
2. 使用高斯加权自适应阈值进行局部分割。
3. 自适应阈值的邻域大小设为 31，常量 C 设为 5。
4. 保存两种结果和水平对比图。
5. 输出全局 Otsu 自动选择的阈值。

异常处理：

- `adaptiveThreshold` 的输入必须是灰度图。
- 邻域大小必须是大于 1 的奇数，本实验固定为 31。
- 图像保存异常由 `save_image` 统一处理。

### 3.7 main

功能：组织程序的整体执行流程。

输入：无。

输出：终端运行信息和全部实验结果图。

处理过程：

1. 创建结果目录。
2. 读取两张实验图片。
3. 输出图片尺寸。
4. 依次调用 Sobel、Canny、全局阈值和自适应阈值函数。
5. 输出实验完成信息。

异常处理：

- 各功能发生异常时不隐藏错误，使终端能够显示具体问题和文件路径。

## 4 数据流

    实验图片
       ↓
    灰度读取与有效性检查
       ↓
    Sobel / Canny / 全局阈值 / 自适应阈值
       ↓
    保存单项结果和对比图
       ↓
    终端输出阈值及边缘密度

## 5 参数设计

| 参数 | 数值 | 作用 |
|---|---:|---|
| Sobel 核尺寸 | 3、5 | 比较边缘细节和平滑程度 |
| Canny 双阈值 | 50/150 | 保留较多弱边缘 |
| Canny 双阈值 | 100/200 | 平衡细节和噪声 |
| Canny 双阈值 | 150/250 | 主要保留强边缘 |
| 固定分割阈值 | 128 | 与自动阈值进行比较 |
| 自适应邻域大小 | 31 | 计算局部阈值的邻域范围 |
| 自适应常量 C | 5 | 调整局部阈值的大小 |
