# 实验一需求规格

## 1 项目概述

本项目面向需要处理动漫与图形素材的学生和初学者，建立一个稳定、可复现的基础图像处理程序。用户通过命令行提供静态图像的输入路径和灰度图像的输出路径。程序负责读取图像、检查尺寸与数据类型、识别通道数量、完成灰度转换并保存处理结果，同时输出运行状态和耗时信息。输入主要包括 PNG 和 JPEG 文件，输出为可正常读取的灰度图像。本实验只建立后续图像处理模块的公共入口，不包含复杂图像增强、目标识别、实时摄像头处理和图形用户界面。

## 2 功能需求

| 编号 | 功能需求 | 验证方法 |
| --- | --- | --- |
| FR-01 | 程序应通过命令行参数接收输入图像路径和输出图像路径。 | 运行程序并检查参数帮助及路径解析结果。 |
| FR-02 | 给定存在且可解码的图像，程序应成功读取并输出 shape、dtype 和通道数。 | 使用彩色 PNG 运行 T01，检查控制台日志。 |
| FR-03 | 程序应将三通道 BGR 图像转换为单通道灰度图像。 | 运行 T01，读取输出文件并检查其维数。 |
| FR-04 | 输入已经是灰度图像时，程序应直接保留其单通道数据并正常保存。 | 使用灰度 PNG 运行 T04，检查运行状态和输出属性。 |
| FR-05 | 输出目录不存在时，程序应自动创建目录并保存灰度结果。 | 删除指定输出目录后运行 T08，检查目录和文件是否生成。 |

## 5 用例

### UC-01 正常处理

- 前置条件：输入路径指向可读取的彩色图像。
- 操作：通过命令行传入输入路径和输出路径。
- 预期结果：程序输出图像属性和成功状态，并生成单通道灰度图像。

### UC-02 文件不存在

- 前置条件：输入路径不存在。
- 操作：使用不存在的文件路径运行程序。
- 预期结果：程序提示读取失败，不生成输出文件，并以非零状态码退出。

### UC-03 灰度输入

- 前置条件：输入路径指向可读取的灰度图像。
- 操作：通过命令行运行程序。
- 预期结果：程序识别单通道图像，不访问不存在的第三通道，并正常保存结果。

### UC-04 输出目录不存在

- 前置条件：输入有效，指定的输出目录尚未创建。
- 操作：通过命令行运行程序。
- 预期结果：程序自动创建输出目录并保存灰度图像。

## 7 图像数据约定

- 彩色图像通常表示为 `(H, W, 3)`，灰度图像通常表示为 `(H, W)`。
- 图像中的像素使用 `image[y, x]` 访问，其中 `y` 表示行，`x` 表示列。
- OpenCV 默认使用 BGR 通道顺序，Matplotlib 显示彩色图像时通常使用 RGB 顺序。
- 常见 `uint8` 图像的像素取值范围为 0 至 255。
- 三通道和四通道输入将转换为灰度图像；单通道灰度输入直接保存。
- 原始图像保存在 `data/input`，程序输出保存在 `data/output`，不得覆盖原始数据。
